# ElevateWeb — Cuberto-Style Digital Product Store

High-impact, kinetic digital product store for **elevateweb.me** built with **React 18 + TypeScript + Vite + Tailwind CSS + GSAP + Lenis**, styled after the iconic design language of **[Cuberto](https://cuberto.com/)**.

Featuring the flagship product: **[90 Days Comeback Plan on Whop](https://whop.com/elevateweb-b83f/90-days-comeback-plan/)**.

---

## 🎨 Cuberto Design DNA & Features

1. **Giant Editorial Typography (`Syne` + `Plus Jakarta Sans`)**:
   - Massive 8rem heading layouts with tight negative tracking (`-0.03em`) and leading (`0.98`).
   - Clean, confident typography with zero generic gradient fluff.

2. **Dynamic Section Inversion**:
   - Seamless transition from clean, high-contrast white tophead (`#ffffff`) into deep pitch-black (`#000000`) for the selected work and product catalog.

3. **Cuberto Custom Magnetic Cursor (`<CubertoCursor />`)**:
   - Smooth lerp follower dot that expands into labeled interactive badges (`EXPLORE`, `VIEW`, `BUY`, `CART`, `CLOSE`).
   - Automatic touch-device fallback.

4. **Cuberto Interactive Rubber-Band String Dividers (`<CubertoDivider />`)**:
   - Interactive SVG string dividers across sections that dynamically bend, deflect, and bounce with elastic spring physics on mouse hover.

5. **Showreel Flagship Showcase (`<CubertoShowreel />`)**:
   - Massive 16:9 rounded stage (`border-radius: 2.5rem`) featuring the **90 Days Comeback Plan** with interactive 3D perspective mouse tilt, Whop pricing (₹999 / 20% off), deliverables checklist, and sample reader.

6. **Interactive Capabilities & Curriculum Accordion (`<CubertoFeatures />`)**:
   - Dynamic 5-pillar accordion syncing with real-time visual media changes on hover/click.

7. **Asymmetric 2-Column Pitch-Black Product Grid (`<CubertoProducts />`)**:
   - Pitch-black container with zoom-on-hover card physics (`scale(0.975)` container, `scale(1.08)` inner image).
   - Quick Add to Cart with functional Drawer and direct Whop Instant Access links.

8. **Operator Proof & Testimonials (`<CubertoTestimonials />`)**:
   - Clean quote cards highlighting real turnaround metrics from operators and founders.

9. **Massive Outro & Magnetic Footer (`<CubertoOutro />` & `<CubertoFooter />`)**:
   - Giant call-to-action with smooth Lenis back-to-top scroll.

10. **Full Payment Stack**:
    - Razorpay payment checkout integration + direct Whop checkout links.
